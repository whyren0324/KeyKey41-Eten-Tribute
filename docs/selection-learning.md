# 選字學習保存

2026-10-07：右 Shift 單按切換中英文；選字學習支援跨後端重啟保存。

## 儲存與行為

後端啟動時載入 `%APPDATA%\KeyKey41\selection-learning-v1.txt`，每次人工選詞後寫回。
此檔與手動使用者詞庫分開；不會修改原始詞庫，也不會上傳資料。
保存的是彙總次數、最近選用時間及有限上下文，並非全文打字紀錄。

選詞、Tab 改選及聯想選詞會記錄；純注音選字會記錄，但該模式候選排序尚未使用偏好。
自動猜出的結果不累加為人工選用。取消組字不回滾此前的選字紀錄。
上下文建議先套用，無建議才按同讀音偏好尋找候選，優先較長讀音候選。
移除三字上限與低分候選篩除；可學詞長仍受現有引擎候選範圍限制。

最多 10,000 個觀察鍵，超過時淘汰最久未更新的鍵；半衰期 90 天。
這是參考長期詞頻學習的本地改良，不是直接整合 Rime；目前仍採時間衰退。
每次選字同步儲存完整快照，未做背景批次寫入；大紀錄量的延遲需後續實機觀察。

## 檔案與故障處理

第一行 `KEYKEY_LEARNING_V1`，其餘各行為：

```text
"observation key" "candidate" count timestamp forceHighScore
```

字串採 C++ `std::quoted` 跳脫，UTF-8；timestamp 為 epoch 秒。
`reading:` 前綴代表不依上下文的讀音偏好，其餘為既有模型上下文鍵。
寫入同目錄 `.tmp` 再以 Windows replace/move 切換。寫入失敗記日誌。
格式錯誤時保留原檔並禁用本次執行的寫回，記憶體中仍可學習。
需要清除／修復時，先停止後端，備份該檔，再移走該檔並重啟；不要在執行中編輯。
